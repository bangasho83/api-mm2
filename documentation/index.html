About this documentation

Each page below corresponds to one STU from the SR&ED claim. It presents the full hypothesis progression (H1 → STA), documents each failed or negative result with actual production code or pseudocode, and provides an architectural diagram illustrating the investigation path. The final STA describes the principle reached and its transferability.
