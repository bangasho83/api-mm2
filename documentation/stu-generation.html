Architectural uncertainty in designing a structured-context-to-creative-output pipeline for multi-modal generative models whose behaviour under composed structured context is not specified by their documentation.

Scientific and Technological Uncertainty (STU)

It was not known whether a structured-context-to-creative-output pipeline — combining brand guidelines, creative direction, and generation instructions — could reliably produce on-brand ad creative using black-box generative models (Imagen4, Flux-kontext, Nano Banana) whose behaviour under composed structured context is not specified in their published documentation.

H1 — Single Composed Prompt (All Context Collapsed)

All structured context (brand guidelines, creative direction, generation instruction) collapsed into a single prompt string and submitted to Imagen4. Model behaviour under composed structured context is not specified in Imagen4 documentation. Empirical testing revealed high output variance; structural context beyond ~200 tokens was poorly reflected in output.

H3 — Multi-Step Generation Pipeline (LLM Prompt Generation + Model Call)

LLM (gpt-4o) pre-processes structured brand and creative context into a generation prompt before the image model call. Image-to-prompt extraction also introduced as a pre-call intervention. Prompt quality improved — but downstream image model output variance did not reduce proportionally. Conclusion: variance is a pipeline property, not a prompt property.

H4 — Validation-and-Retry Loop (Reliability as a Pipeline Property)

Reliability enforced at the pipeline layer: post-generation output shape validation, pre-call URL and format guards, bounded timeout via withTimeout, and multi-model routing that isolates model-specific failure modes. Each model carries a distinct variance profile; routing selects model class based on context type, not preference.

// api/image-gen.js : 14–20
// PSEUDOCODE: H4 — bounded timeout enforced at pipeline layer
function withTimeout(promise, ms, label = 'operation') {
  return Promise.race([
    promise,
    new Promise((_, reject) =>
      setTimeout(() => reject(new Error(`${label} timeout after ${ms}ms`)), ms)
    )
  ]);
  // Termination bound enforced by the pipeline, not by the model.
  // Consistent with reliability-as-pipeline-property principle.
}

Scientific and Technological Advancement (STA)

Validation-feedback architecture for variance absorption in black-box generative pipelines. Core principle: reliability is a pipeline property, not a model property. Pre-call interventions (LLM prompt generation, image-to-prompt extraction, URL validation) were demonstrated empirically to move but not reduce variance at the generation boundary. Post-generation output shape validation enforces reliability at the pipeline layer independently of which model is invoked. Multi-model routing isolates model-specific failure modes rather than exposing them to the consumer. Bounded termination (withTimeout) enforced by the pipeline. Principle transferable across generative modalities: any pipeline built on black-box generative models whose behaviour under structured context is not fully specified must enforce reliability at the pipeline boundary, not assume it from the model.
